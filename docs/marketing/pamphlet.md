# Printed material

Pamphlet, flyer, visiting card and shop-door sticker. Replace every
`{{placeholder}}` before sending to the press — a printed placeholder is an
expensive mistake. See [README.md](README.md) for the claims policy.

> **Proofread the Devanagari on the physical proof, not the screen.** Cheap
> presses substitute fonts and break conjuncts (क्ष, त्र, ज्ञ). Ask for one
> printed copy before the full run.

---

## A5 pamphlet — single side

Give this to a shopkeeper in hand. It has to work in the ten seconds before
they put it down.

```
│                                              │

│         बिलिंग चलती रहेगी                     │
│                                              │
│      नेट आते ही सब अपने आप सेव                 │
│                                              │
├──────────────────────────────────────────────┤
│                                              │
│   ✅ उधार खाता — किसका कितना बाकी, तुरंत      │
│   ✅ GST बिल — एक टैप में                     │
│   ✅ बारकोड स्कैन करके बिल                    │
│   ✅ स्टॉक अलर्ट — खत्म होने से पहले           │

│   किराना · कपड़ा · फुटवियर · मोबाइल          │
│   दवाई · हार्डवेयर · स्टेशनरी · फर्नीचर       │
│   कॉस्मेटिक्स · रेस्टोरेंट                    │
│                                              │
├──────────────────────────────────────────────┤
│                                              │
│              💰 {{PRICE}}                    │
│                {{TRIAL}}                     │
│                                              │
│         📞 {{PHONE}}                         │
│         🌐 {{WEBSITE}}                       │
│                                              │
│            [ QR कोड यहाँ ]                    │

│                                              │
└──────────────────────────────────────────────┘
```

**Design notes for whoever lays this out:**

- The offline line is the reason anyone keeps this pamphlet. Give it the most
  space and the strongest weight — bigger than the logo if needed.
- Minimum 11pt for the feature list. This is often read by someone in their
  fifties, in shop lighting, without reading glasses to hand.
- Put the QR where a thumb naturally sits, and **scan the printed proof
  yourself** before the full run.
- Keep one clear number. Two numbers means neither gets called.

## Market banner / hoarding

Six words at most. Read at distance, in traffic, in two seconds.

**Option A (the strongest):**

```
     नेट बंद? बिलिंग फिर भी चालू।

              ARTHA
        {{PHONE}} · {{WEBSITE}}
```

**Option B:**

```
   उधार, GST, स्टॉक — सब एक ऐप में

              ARTHA
        {{PHONE}} · {{WEBSITE}}
```

**Option C (English-medium areas):**

```
    Billing that works without internet

              ARTHA
        {{PHONE}} · {{WEBSITE}}
```
