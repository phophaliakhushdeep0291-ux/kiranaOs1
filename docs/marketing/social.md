## Reels / Shorts scripts

Each is built around **one** idea. Shoot in a real shop, on a real counter,
with a real customer if they agree — staged-looking footage gets scrolled past.

### Script 1 — "Net gaya" (the strongest hook you have)

> **Length:** 20–25s

| Time | On screen | Voice / text |
|---|---|---|
| 0–3s | Router with no lights, or a phone showing "No internet" | "Net chala gaya." |
| 3–6s | Shopkeeper's face — calm, shrugs | "Aur billing?" |
| 6–14s | Close-up: items scanned, bill made, printer prints | "Chalti rahi." |
| 14–19s | Wi-Fi reconnects; sync indicator turns green | "Net aaya — sab apne aap upload." |
| 19–25s | Logo + link | "Artha. {{WEBSITE}}" |

**Caption:**

```
Net band ho jaye to dukaan band nahi hoti. Billing bhi nahi rukni chahiye.

Artha offline chalta hai. Bill bante rahenge, aur net wapas aate hi
sab apne aap sync ho jayega.

{{TRIAL}} 👉 {{WEBSITE}}

#billingapp #kiranastore #dukaan #offlinebilling #gstbilling #smallbusinessindia
```

### Script 2 — "Udhar kitna hai?"

> **Length:** 15–20s

| Time | On screen | Voice / text |
|---|---|---|
| 0–4s | Cluttered paper udhar register, pages flipping | "Kiska kitna udhar hai?" |
| 4–8s | Frustrated flipping, squinting at old entries | "Register mein dhoondhte raho…" |
| 8–15s | App: customer tapped, balance and history appear instantly | "Ya ek tap." |
| 15–20s | Payment recorded, balance drops | "Payment liya — balance turant update." |

**Caption:**

```
Udhar ka register sabse purana bhi hai, aur sabse mushkil bhi.

Artha mein har customer ka balance turant dikhta hai — kitna baaki hai,
kab liya tha, kab diya tha. Payment lete hi update.

👉 {{WEBSITE}}

#udhar #khata #kiranastore #billingapp #dukaandari #smallbusinessindia
```

### Script 3 — "Din ka hisaab"

> **Length:** 20s

| Time | On screen | Voice / text |
|---|---|---|
| 0–5s | Night. Counting cash by hand, confused expression | "Roz raat ko yahi sawaal —" |
| 5–9s | Text on screen | "galti kahan hui?" |
| 9–16s | Daily closing screen: expected vs counted, difference | "Ab app khud batata hai." |
| 16–20s | Logo + link | "Artha. {{WEBSITE}}" |

**Caption:**

```
Din bhar ki bikri, cash, UPI, udhar, kharcha — raat ko sab milana
sabse thakane wala kaam hai.

Artha ka daily closing khud jodta hai: kitna aana chahiye tha, kitna
aaya, aur farq kitna hai.

👉 {{WEBSITE}}

#dailyclosing #cashmanagement #kiranastore #billingapp #dukaan
```
